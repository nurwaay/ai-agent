# AI Agent

## Описание проекта

AI Agent — веб-приложение с элементами искусственного интеллекта.

Пользователь вводит запрос, после чего AI-агент анализирует запрос
и формирует ответ.

## Основные возможности

- обработка запросов пользователя;
- взаимодействие с AI;
- отображение результатов;
- работа через веб-интерфейс.

## Технологии

- Python
- FastAPI
- HTML
- CSS
- JavaScript
- Git
- GitHub
- GitLab CI
- Jenkins

## Цель проекта

Разработать веб-приложение AI Agent и организовать процесс разработки
с использованием Git, GitHub, GitLab CI и Jenkins.
Dev branch version: AI Agent development environment.
Feature branch version: AI Agent with smart response module.
## Git Workflow

В проекте используется следующая схема работы с Git.

### Ветки

- `main` — стабильная версия проекта.
- `dev` — основная ветка разработки.
- `feature/*` — ветки для разработки отдельных функций.

### Правила работы

1. Новая функциональность разрабатывается в отдельной ветке `feature/*`.
2. Feature-ветка создаётся на основе ветки `dev`.
3. После завершения разработки изменения сохраняются с помощью commit.
4. Готовая feature-ветка объединяется с веткой `dev`.
5. Ветка `main` используется только для стабильной версии проекта.
6. Перед merge необходимо проверить изменения и убедиться, что проект работает корректно.

### Роли участников

- Developer — разрабатывает новые функции и создаёт commits.
- Reviewer — проверяет изменения перед объединением веток.
- Maintainer — отвечает за объединение изменений в `dev` и `main`.
