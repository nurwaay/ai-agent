# AI Agent

## Описание проекта

AI Agent — веб-приложение с элементами искусственного интеллекта.

Пользователь вводит запрос, после чего AI-агент анализирует запрос
и формирует ответ.

## Основные возможности

- обработка запросов пользователя;
- взаимодействие с AI;
- отображение результатов;
- работа через веб-интерфейс.

## Технологии

- Python
- FastAPI
- HTML
- CSS
- JavaScript
- Git
- GitHub
- GitLab CI
- Jenkins

## Цель проекта

Разработать веб-приложение AI Agent и организовать процесс разработки
с использованием Git, GitHub, GitLab CI и Jenkins.
